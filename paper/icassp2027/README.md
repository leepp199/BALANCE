# ICASSP 2027 manuscript workspace

The official 2027 author page currently specifies at most four pages of technical
content and an optional fifth page restricted to references, funding acknowledgements,
and the ethics statement. The downloadable 2027 paper kit was not yet exposed when this
workspace was created (2026-08-16), so `main.tex` uses `IEEEtran` as a temporary class.
Replace only the class/style files when the official kit appears; do not migrate content
back to an older ICASSP kit.

Generated numerical tables come from `../../scripts/make_paper_tables.py`. Values marked
`TBD` are intentionally unavailable until the corresponding ten-repeat job finishes.
The authoritative prose draft remains `../../docs/ICASSP_DRAFT_V1.md` while this compact
version is being fitted to the conference page limit.
